# MadeByTrevor — GitHub Pages

A responsive, multi-page developer portfolio with a dark navy and radiant-blue visual style.

## Files
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `services.html` — Services
- `blog.html` — Blog landing page
- `contact.html` — Contact
- `assets/style.css` — Site styling
- `assets/main.js` — Mobile navigation and current year

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `madebytrevor` (or `YOUR-USERNAME.github.io` if you want the root user-site URL).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside another folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the GitHub Pages deployment to complete. Your site will be available at `https://YOUR-USERNAME.github.io/madebytrevor/` (or `https://YOUR-USERNAME.github.io/` for the user-site repository).

## Before launch
- Replace `YOUR-EMAIL@example.com` in `contact.html` with your actual email address.
- Replace the generic LinkedIn and GitHub links with your profiles.
- Add verified repository/demo links and screenshots to `projects.html`.
- Review all profile copy and project descriptions for accuracy.

## Notes
This is a static HTML/CSS/JavaScript website. GitHub Pages can host the portfolio front end, but it does not run a Rust/Axum server or a database. Those parts of a future project need separate hosting and can be connected using an API.
